## 1. Non-Negotiable System Laws

1. **Workspace Isolation & Read-Only Sibling Safety:**
   - All assets, CLIs, schemas, scripts, dossiers, and bilingual books live strictly inside `d:/Youtube channel/reading-room-editorial-os`.
   - `d:/Youtube channel/reading-room-cinema` and root workspace files are never modified during build waves (except explicit dry-run or user-invoked export via `tools/export_cinema_bundle.mjs`).
2. **Live GitHub Persistence (`Commit Every Wave`):**
   - Every wave commits and pushes directly to `origin/main` (`https://github.com/Yuzakhodayari/reading-room-editorial-os`) immediately upon verification.
3. **Late-2027 Staleness Immunity (`30 Videos -> January 2028`):**
   - **Episodes 1, 2, and 3** form the pre-recorded Launch Trio, scripted word-for-word (`3,000+` words each).
   - **Episodes 4 through 30** banish perishable 2026 headlines, single-model version gimmicks, and dated retrospectives. Every episode targets multi-year institutional, financial, physical, legal, or security fault lines where **bold AI shifts lead**, **economy and finance drive the balance-sheet math**, and **daily life, cybersecurity, geopolitics, and tech/social-media policy** show viewers how to react and protect themselves. Spot metrics update on shoot week via `[LIVE_STAT_SLOT]` markers.
4. **Mandatory 6-Stage Script Pipeline:**
   - **Stage 1:** Primary Filing & Data Extraction (Treasury MTS Table 9, FRED, CBO, SEC 10-K/10-Q, BIS, IMF, IEA, PJM/ERCOT, court dockets, NIST/CISA CVEs).
   - **Stage 2:** Adversarial Domain-Expert Stress Test (Macroeconomist, CPA, Grid Engineer, Security Researcher, Tech Lawyer patches baked into the prose).
   - **Stage 3:** `channel-structure` (`R02`/`A16` unspoiled escape-hatch reveals, tight cold-open clock, single lean-matched CTA).
   - **Stage 4:** `channel-storytelling` + `channel-audience` (longitudinal human character stakes, real 18-turning-28 shirt-and-tie generational stake, tactile physical rescaling, decile re-hooks).
   - **Stage 5:** `channel-language` (*AI In Context* 7x + *Max Fisher* 6x + *Gen* 5x + *Maxinomics* 4.5x + *Art of the Problem* 4x + *Patrick Boyle* deadpan understatement; zero profanity, zero YouTuber hype).
   - **Stage 6:** Hard Automated Anti-AI Detector Gate (`score = 0` `HUMAN_ONLY` on `avoid-ai-writing`, `15.5–17.5` mean sentence length, `<8%` sentences `>30` words, `0` em dashes, `0` semicolons, `0` exclamation marks, `0` `"not X, but Y"` crutches, `0` abstract triads, `0` runs of 3 equal-length sentences, `0` banned AI words).
